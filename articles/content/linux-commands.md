
# 20 Linux Commands for Developers

Knowing the Linux command line multiplies your productivity.

## Files and Directories

*   `ls -la`: List all files with details.
*   `chmod +x script.sh`: Make a script executable.
*   `grep -r "text" .`: Search for text in all files.

## Networking

*   `curl -I google.com`: Check response headers.
*   `netstat -tulpn`: View open ports.

## Processes

*   `htop`: Monitor system resources.
*   `kill -9 <PID>`: Forcibly close a program.

ps aux | grep node
